# 智能仿生手 · 抓取档案

本次新增的「视觉感知 → 动作复现」前端流程，基于原有 uni-app（Vue 2）工程。

## 页面

| 页面 | 路径 | 作用 |
| --- | --- | --- |
| 主界面 | `pages/index/index.vue` | 五指舵机实时值、当前识别物品、抓取次数、模拟语音抓取、存入档案、原始数据入口 |
| 抓取档案 | `pages/archive/archive.vue` | 物品图片/舵机序列、搜索、已记录/未记录分类、云端同步、AI 识别、CSV 导出 |
| 原始数据 | `pages/raw/raw.vue` | 设备级云端采样、物品/五指参数表格、手动存入、CSV 导出 |

登录账号为 `HaJi`（密码见工程内配置）。登录成功后进入主界面，只保留「抓取档案」和「原始数据」两个模块；训练监测、康复管理已从页面入口和 `pages.json` 路由中移除（对应源文件仍保留在 `pages/` 下，未注册、不会编译进应用）。

## 数据层

- `utils/archive.js`：物品档案、抓取次数、最近动作、OneNET 合并、CSV 导出。
- `utils/vision.js`：未记录图片的视觉识别服务，支持演示模式、智谱 GLM-4V、通义千问 VL、自定义 OpenAI 兼容接口。
- `utils/media.js`：选图、压缩、转 base64，便于把抓拍图片存进本地档案。
- `utils/cloud.js`：在原有五指属性之外，新增物品相关属性解析。
- `utils/store.js`：设备级原始采样缓存（`RAW_DEVICE_ID = 'device-main'`），与患者档案解耦。

档案保存在本机 storage：

- `grasp_objects_v1`：物品档案
- `grasp_meta_v1`：当前物品、最近抓取、云端同步状态
- `grasp_vision_cfg`：识别服务配置（Key 只在本机）

首次运行会生成 6 条已记录 + 4 条未记录的演示数据，右上角 `⚙` 里可以配置真实视觉 API，归档页可导出 CSV。

## OneNET 物模型（可选扩展）

原有五指属性保持不变：

- `Damuzhi` / `shizhi` / `Zhongzhi` / `wumingzhi` / `xiaomuzhi`

新增物品相关属性，设备端上报后会自动合并进档案：

| 标识符 | 类型 | 说明 |
| --- | --- | --- |
| `wupin` | string | 当前识别物品名称 |
| `wupin_img` | string | 物品图片 URL（可选） |
| `wupin_conf` | number | 识别置信度 0~1（可选） |
| `grab_count` | number | 当前物品累计抓取次数（可选） |
| `ObjectArchive` | string | 云端档案 JSON 字符串（可选） |

`ObjectArchive` 示例：

```json
[
  {
    "name": "水杯",
    "category": "生活用品",
    "image": "https://example.com/cup.jpg",
    "servo": [64, 74, 78, 76, 70],
    "count": 18,
    "confidence": 0.96,
    "graspType": "圆柱抓握"
  }
]
```

已记录档案优先读取 `ObjectArchive`；没有该属性时，使用 `wupin` + 五指属性合并当前物品；都读不到时保留本地缓存/演示档案。设备离线时页面会明确显示「当前显示本地缓存档案」。

## 未记录图片的识别

在抓取档案页点「存入」选择图片（相册/相机），图片进入“未记录”分组。点卡片上的「AI 识别」：

1. 调用 `utils/vision.js` 的识别服务；
2. 返回物品名称、类别、置信度、抓握方式；
3. 按抓握方式给出五指舵机建议值（可手动改）；
4. 确认识别后转为“已记录”，抓取次数从 0 开始累计。

默认是**离线演示模式**，不会联网，返回的是内置样例结果，用于比赛/答辩演示。要接真实识别：

- 右上角 `⚙` → 选择「智谱 GLM-4V」或「通义千问 VL」；
- 填入对应的 API Key；
- 或选择「自定义接口」，填写 OpenAI 兼容的 `/chat/completions` 地址和模型名。

> H5 直连第三方大模型接口时，若对方未开放 CORS，需要在自己的后端做一层转发，再把自定义地址填到设置里。

## 存入键

- 主界面「模拟语音抓取」右侧有「存入档案」键：把当前识别物品和当前五指参数一起写入/更新抓取档案；同名物品会更新舵机序列，不增加抓取次数。
- 原始数据页右上角有「存入」键：读取一次 OneNET 当前属性，写入一条原始采样，并刷新表格。
- 主界面轮询云平台时也会自动写入设备级原始采样，所以从主界面进入原始数据页时通常已经有数据。

## 抓取次数

- 主界面「模拟语音抓取」：复现当前已记录物品的舵机序列，抓取次数 +1；
- 档案详情「复现抓取」：同样 +1，并写入最近抓取记录；
- 云端 `grab_count` / `ObjectArchive[].count` 会在同步时合并，且抓取次数只增不减；
- 档案卡片、详情、主界面都显示对应次数。

## 运行

工程没有 `package.json`，按原 uni-app/HBuilderX 方式运行：打开 `ACCESS_Kangfu`，运行到 H5 或 App。H5 开发端口见 `manifest.json`（8081）。

`pages.json` 当前只注册：登录、主界面、抓取档案、原始数据。训练监测 / 康复管理页面文件保留但未注册，需要恢复时可重新加入路由和入口。

新增的演示物品图片位于 `static/objects/`（SVG 源文件 + PNG 运行版本）。
